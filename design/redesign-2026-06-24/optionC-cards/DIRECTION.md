# Roomie — Playful Card-First (2026-06-24)

**Big idea:** big, expressive, tactile CARDS that fill the screen — joyful and energetic
(BeReal / Duolingo / Cash App), made cohesive by the deep-green palette. The important
thing on every screen is LARGE and grabbable (a €15 hero, a "your turn" hero), not a thin
floating list. Space is used by making one thing hero-sized, then organizing the rest into
confident, scannable card-modules — the opposite of sparse minimalism.

## How it uses the whole screen
- **Hero card per screen** carries the one thing that matters (oversized friendly number /
  big avatar / fat primary button). It anchors the top third.
- **Module cards** below: each is a tappable surface (kitchen mini-grid, balances, history
  timeline). Cards bleed edge-to-edge with generous padding — no wasted gutters.
- **Numbers are HUGE** (Baloo 2, 54–62px) so balance + counts read instantly.
- **Texture & pop:** dotted "money confetti" decor, soft shadows with chunky button drop-
  edges (5px solid) for a tactile, pressable feel.

## Navigation chrome (the missing pieces, now present)
- **Top app bar:** hamburger (menu) · household switcher (crest + name + chevron) · profile
  avatar. Present on every screen.
- **Bottom tabs:** Home · Money · Kitchen · Tasks (active = green pill).
- **FAB** (coral) for the primary add action.

## Palette / type
Deep forest green `#1A6B43` leads (heroes, primary, active tab). Coral / pink / gold pop on
top of it. Identity colors: You = green, Kai = coral, Vfya = pink. Baloo 2 display + Nunito body.

## Locked rules kept
Soft chore language ("your turn", "you did it", "moved on from") · chronological history only ·
**no streaks, no points, no scores, no leaderboards, no shame.**
