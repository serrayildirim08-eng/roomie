# Direction B — Editorial Header + Smart Density

**One line:** Every screen opens with a bold designed header zone that sets context and carries the hero info; below it, a dense but rhythmic body where a lot of useful info is legible at once.

## The big idea
- **Header zone** = forest-green gradient block, rounded bottom. Holds: top app bar (hamburger menu + household name + your avatar), an editorial large title, member avatars, and a 3-up stat strip with the screen's most important numbers. This is the "use the whole top of the screen" move — context + hero info, not a thin bar.
- **Dense body** = segmented controls (Activity/Balances/Mine · Shopping/Pantry), filter chips, day-grouped sections, grouped cards with leading icons, a 2-col pantry grid, and a vertical timeline for history. Density comes from alignment + rhythm, not from shrinking type.
- **Primary action** = floating add button (forest, coral on Kitchen) on every screen.

## Reference anchors
- Things 3 (calm grouped lists), Splitwise (money clarity), Linear mobile (header + dense list), Apple large-title nav.

## Palette
- Lead deep forest #1A6B43 / #268A57 gradient headers. Coral / pink / gold used sparingly (spotlight, low-stock, accents). Warm neutral canvas, near-black ink. Each roommate has an identity color: You=forest, Kai=blue, Vfya=pink.
- Fonts: Baloo 2 (display) + Nunito (body).

## Locked rules honored
- No streaks, no points, no scores, no leaderboards, no shame. Chores use soft language ("your turn · no rush", "whenever suits you") + chronological history timeline only.
