# Roomie — Vibrant direction (2026-06-24)

The warm-linen/oat/terracotta look is **dead**. This is bold, candy-pop, alive —
BeReal/Duolingo energy — but it stays ADHD-calm: one big focus per screen, few
words, nothing to score. **DEEP-GREEN-LED** — a rich forest/pine green is the star
across every screen (heroes, primary buttons, active tab). The dark green makes the
coral/pink/gold supporting accents really pop; violet is one tiny touch (title dot).

## IA / layout law (the Marie-Kondo pass)
- **One list grid, everywhere.** Every row = `[uniform leading dot] [name+sub] [one
  trailing slot]`. Rows in a section are siblings, not three different widgets.
- **Each section owns ONE trailing affordance + ONE meaning.** The header carries
  the state ("to buy", "whose turn") so rows never repeat it. No "out / out / out".
- **One idea, one place.** Pantry shows what the house HAS (quiet coral dot = running
  low). Anything that's OUT lives only on the shopping list — same entity, shown once.
- **Calm hierarchy:** name = medium weight, status = small grey, timestamps = faint.
  One hero leads per screen (brain-dump / €15 / "your turn"); the rest recede.
- **No toy emoji in lists.** A single uniform leading mark gives every row the same
  visual weight; coral appears only where it earns it (Vfya identity, running-low).

- **Nunito** — friendly body: everything else.

## Locked product rules kept
One focus/screen · soft chore language ("your turn", "you did it", "moved on from")
· chronological history only · **no streaks, no points, no counts, no leaderboards.**
